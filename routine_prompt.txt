## STEP 5 — Analyze

Consider ONLY the data in the context object:
- **Trend**: sign of close_vs_sma20_pct, close_vs_sma50_pct; sma20_vs_sma50
- **Momentum**: rsi14 (>70 = overbought, <30 = oversold), macd_hist
- **Volatility**: atr14_pct_of_close
- **Recent**: prev_day_direction, prev_day_pct, last 5 bars
- **News**: net positive/negative/mixed for SPY? Ignore non-equity items.

Confidence: 50-60% (conflict), 60-75% (moderate), 75-85% (strong), 85%+ (rare).
Be honest. Coin-flip predictions stay coin-flip.

## STEP 8 — Push via GitHub REST API

Read the current predictions.jsonl file, append the new line, and commit back:

```bash
export GH_TOKEN='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'
export OWNER='The-25th-ProgRAMmer'
export REPO='stock_predictor'
export FILE='logs/predictions.jsonl'
export BRANCH='main'

# Read current file and its SHA
CURRENT=$(curl -s -H "Authorization: token $GH_TOKEN" \
  "https://api.github.com/repos/$OWNER/$REPO/contents/$FILE" | \
  python3 -c "import sys, json; d=json.load(sys.stdin); print(d.get('content',''), d.get('sha',''), sep='|')")

CONTENT_B64=$(echo "$CURRENT" | cut -d'|' -f1)
CURRENT_SHA=$(echo "$CURRENT" | cut -d'|' -f2)

# Decode, append new line, re-encode
if [ -z "$CONTENT_B64" ]; then
  NEW_CONTENT=$(cat logs/predictions.jsonl)
else
  NEW_CONTENT=$(echo "$CONTENT_B64" | base64 -d)$'\n'$(tail -1 logs/predictions.jsonl)
fi
NEW_B64=$(echo -n "$NEW_CONTENT" | base64 -w0)

# Push via API
curl -s -X PUT -H "Authorization: token $GH_TOKEN" \
  -H "Content-Type: application/json" \
  -d "{
    \"message\": \"Daily prediction $(date -u +%Y-%m-%d)\",
    \"content\": \"$NEW_B64\",
    \"sha\": \"$CURRENT_SHA\",
    \"branch\": \"$BRANCH\",
    \"committer\": {\"name\": \"Trading Bot\", \"email\": \"santhush328@yahoo.co.uk\"}
  }" \
  "https://api.github.com/repos/$OWNER/$REPO/contents/$FILE" | \
  python3 -c "import sys, json; r=json.load(sys.stdin); print('Pushed' if 'commit' in r else f\"ERROR: {r.get('message','unknown')}\");" || echo "PUSH FAILED"
```
